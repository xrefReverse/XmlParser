# XmlParser

Лёгкий XML DOM-парсер на C++ без зависимости от MSVC CRT.

Парсер написан для небольших нативных приложений, загрузчиков, игровых инструментов и проектов, где важны минимальный размер бинарника, контроль памяти и отсутствие стандартного runtime.

## Особенности

- Полностью без линковки с MSVC CRT
- Нет `std::string`, `std::vector`, `malloc`, `free`, `new` и `delete`
- Собственный arena allocator
- Минимальное количество зависимостей
- Работа напрямую с исходным буфером без лишнего копирования
- Поддержка вложенных XML-элементов
- Поддержка атрибутов
- Поддержка текста и CDATA
- Поддержка XML-комментариев
- Поддержка XML-декларации
- Проверка закрывающих тегов
- Обнаружение дубликатов атрибутов
- Ошибки с позицией: offset, line, column
- Поддержка UTF-8 в исходном XML и консоли
- Удобный интерфейс в стиле `XElement`

## Пример использования

```
#include "xmlparser.hpp"

extern "C" int WINAPI entry() {

const char *xml = "<hello attr='hello parser' attr2='Привет парсер!'/>";
xml::Error error = {};
xml::XElement document = xml::XElement::parse(xml, &error);

if (!document.valid()) {
  crt::printf("failed parse\n");
  return -1;
}

crt::printf("attr: ");
print(document.Attribute("attr"));
crt::printf("\nattr2: ");
print(document.Attribute("attr2"));
crt::write_string("\n", 1);

return 0;

}

```
Управление памятью
Парсер выделяет один arena-блок памяти под DOM-дерево. Все узлы и атрибуты размещаются внутри этого блока.
При использовании xml::Document память освобождается вручную

```
xml::destroy(&document);
```

При использовании xml::XElement память освобождается автоматически в деструкторе.
Ограничения
Проект ориентирован на Windows и использует WinAPI для:
- выделения памяти;
- чтения файлов;
- вывода в консоль;
- работы с UTF-8-кодировкой консоли.
Исходный XML-буфер должен оставаться доступным, пока используется DOM-дерево, поскольку строки представлены как Slice без копирования.

MSVC CRT не используется. Для вывода реализована собственная функция:

```
crt::printf("value: %d\n", value);
```
